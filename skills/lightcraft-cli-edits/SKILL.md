# LightCraft CLI Edits

Use `lightcraft_run` with `cli_args: ["--help"]` to inspect the installed CLI. Use your configured LightCraft workflow for edits. Save to a new path, inspect the exact export with `artcraft_inspect`, and use `artcraft_verify_edit` when the source and output are comparable raster images.
